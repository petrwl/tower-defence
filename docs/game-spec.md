# Game Spec — Tower Defense

Эталонное ТЗ. При расхождении с кодом — сначала обновить spec, потом код (или наоборот, но зафиксировать в session-файле).

## Общие ограничения

- Один HTML-файл, Canvas, чистый JavaScript
- Без внешних библиотек
- 60 FPS, без тяжёлых вычислений в game loop
- Адаптивный UI для экранов ≥ 1280×720

## Поле и путь

- Сетка **10×10**, клетка **50×50 px** (canvas 500×500)
- Путь: **зигзаг** от левого края (вход) до правого (выход)
- Клетки пути — **светло-серые**, остальные — **зелёные** (трава)
- Враги движутся по заданным координатам waypoints

## Враги

| Параметр | Значение |
|---|---|
| Визуал | Красный круг, HP внутри |
| Волна | 5 врагов, интервал спавна 0.5 сек |
| HP волна 1 | 20 |
| HP волна 5 | 50 (линейный рост между волнами) |
| Скорость | 1 px/кадр |
| Награда | 10 монет за убийство |

## Башни

| | Стрелок | Маг |
|---|---|---|
| Урон | 10 | 25 |
| Дальность | 150 | 120 |
| Цена | 50 | 100 |
| Особенность | — | Замедление 50% |

- Установка: клик по свободной зелёной клетке → меню выбора
- Нельзя ставить на путь
- Анимация: летящий снаряд к цели

## Экономика

- Старт: **100 монет**, **10 жизней**
- HUD: монеты и жизни — верхний левый угол
- Враг дошёл до выхода → −1 жизнь; при 0 → Game Over

## Волны

- Кнопка «Следующая волна» внизу экрана
- Номер текущей волны на экране

## UI

- Минималистичный дизайн
- Панель башен с иконками и стоимостью
- Подсветка выбранной клетки

## Debug (бонус)

- Панель по клавише **D**
- Ползунки/поля: скорость врагов, HP, стоимость и урон башен
- Изменения применяются без перезапуска
