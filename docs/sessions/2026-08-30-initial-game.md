# 2026-08-30 — Initial Tower Defense

## Prompt

> Создай полноценную игру Tower Defense в одном HTML-файле с Canvas и чистым JavaScript. Сетка 10×10, зигзагообразный путь, волны врагов, две башни (Стрелок и Маг), экономика, debug-панель по клавише D.

Полный текст ТЗ — в [game-spec.md](../game-spec.md).

## Result

- Создан `index.html` (~400 строк): HTML + CSS + JS в одном файле
- Canvas 500×500, сетка 10×10, путь по строкам 1–5 (зигзаг)
- Враги: красные круги с HP, волны по 5, спавн каждые 0.5 сек
- Башни: Стрелок (🏹) и Маг (✨), меню по клику или режим установки с панели
- Снаряды летят к цели; маг замедляет на 50% на 2 сек
- HUD (монеты, жизни), номер волны, кнопка «Следующая волна»
- Game Over + перезапуск; debug-панель (D) для баланса
- Проект перенесён в отдельный репозиторий `towerdefence`

## Decisions

| Решение | Причина |
|---|---|
| Путь зигзагом по фиксированным строкам 1–5 | Проще waypoint-логики, без pathfinding |
| HP = `20 + (wave − 1) × 7.5` | Линейный рост: 20 на 1-й волне, 50 на 5-й |
| Один файл вместо модулей | Требование ТЗ, минимальный размер, открывается напрямую в браузере |
| `docs/sessions/` — один файл на сессию | Баланс между детализацией и порядком |
