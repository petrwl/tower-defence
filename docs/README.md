## Как вести

1. **Новая сессия** — создайте `sessions/YYYY-MM-DD-краткое-описание.md` по [шаблону](sessions/_template.md).
2. **Изменение в коде** — добавьте строку в [CHANGELOG.md](../CHANGELOG.md).
3. **Commit** — сообщение вида `feat: …`, `fix: …`, `docs: …`.

Промпты и ответы AI храним выжимкой, не полным дампом. Детали кода — в git.
